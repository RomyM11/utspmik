Ini adalah Project UTS Keamanan dan Perlindungan Data

Cara Menginstall Project Ini:
1. Download File dan Ekstraxt file "utspmik-main.zip"
2. Buka folder utspmik-main lalu copy sub foldernya "utspmik" yang didalamnya sudah ada file Project
3. Jalankan Apache dan MySQL di Xampp
4. Buka browser lalu ketik "localhost/utspmik"
